# Rules for every run

Read this file, `HITL.md` and `LOG.md` before you do anything.

- Write one report per run, then stop.
- Never commit, push, delete files or call a paid API.
- The run is done only when `./check.sh` passes.
- If you have a question or you are unsure, do not guess. Add the question to `HITL.md` and stop.
- At the end of each run, add one line to `LOG.md`: date, pass or stopped, one fact.
