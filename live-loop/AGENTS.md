# Rules for every run (the harness)

Read this file, `HITL.md` and `LOG.md` before you do anything.

- Do one task per run, then stop.
- Write only inside this folder. Never run shell commands.
- If a task is unclear, do not guess. Add the question to `HITL.md` in this form, leave the task's box unchecked, and stop:

  ## Run N: <the task>
  **Question:** <your question>
  **Answer:**

- A question in `HITL.md` with an empty answer is open. Skip that task and take the next one.
- A question in `HITL.md` with an answer is closed. Use the answer to do that task.
- At the end of each run, add one line to `LOG.md`: `- run N: done, <task>` or `- run N: stopped, question in HITL.md`.
