# Goal for one run

First read `AGENTS.md`, `HITL.md` and `LOG.md`.

Read the git log of this repo for the last 24 hours. Write a short report to
`reports/YYYY-MM-DD.md` (today's date) with three headings:

## What changed
## What looks risky
## What to do next

Then run `./check.sh`. When the check passes, add one line to `LOG.md` and stop.
